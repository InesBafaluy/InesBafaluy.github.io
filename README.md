# inesbafaluy.github.io

My personal portfolio website: **[inesbafaluy.github.io](https://inesbafaluy.github.io)**

It presents my projects, experience, education and activities, with links to reports and code.

The site is available in four languages:
[English](https://inesbafaluy.github.io) · [Français](https://inesbafaluy.github.io/fr/) · [Català](https://inesbafaluy.github.io/ca/) · [Español](https://inesbafaluy.github.io/es/)

## Structure

```text
├── index.html     English version
├── fr/  ca/  es/  French, Catalan and Spanish versions
├── style.css      Styles (light and dark mode)
├── assets/        Photo and organisation logos
└── reports/       Project reports (PDF)
```

Plain HTML and CSS, hosted on GitHub Pages.

Organisation logos belong to their respective owners and are used only to identify where each experience took place.
